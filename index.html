METABOLOMICS / SIGNAL PROCESSING

CE-SICRIT-MS

Oscillation correction in mass spectrometry.

A Python tool for detecting and correcting oscillatory artefacts in mass spectrometry signals. It combines FFT analysis, sinusoidal modelling and export of corrected spectra in mzML format.

Package release: Planned for distribution on PyPI.

PythonNumPyFFTCLI · mzML
Explore the project +

The challenge

Detect oscillatory artefacts in CE-SICRIT-MS signal intensities and correct them during metabolomics data processing.

My contribution

Development of the correction algorithm: reconstructing the residual signal by subtracting a sinusoidal component estimated from amplitude and phase.

How it works

Read mzML/mzXML files, detect oscillatory signals using FFT, correct intensities and write mzML output. The CLI supports individual files and folders.

Deliverable

Python code organised into input/output, processing, analysis and validation modules, with automated tests and sample files in the repository.
